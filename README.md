# Платформа домов

Агрегатор застройщиков и услуг для дома (форк идеи PLATFORMA). Next.js 16, TypeScript, чистый CSS.

## Что есть
- Каталог: застройщики (строят и продают / под заказ / готовые дома) и услуги (забор, кровля, гараж, плитка, покос, мусор, септик, снег)
- SEO: страницы категория и категория+район, FAQPage и BreadcrumbList JSON-LD, sitemap, robots, canonical
- Регистрация партнёра за 3 шага: телефон, категории, район. Страница `/p/<slug>` создаётся сразу
- Чат клиента на странице партнёра, переписка хранится на платформе. Копия всего уходит админу в Telegram
- Партнёр отвечает в Telegram («Ответить» на заявку) или в кабинете `/cabinet/<token>`
- Лид засчитывается при первом ответе партнёра. До этого телефоны и ссылки в сообщениях клиента скрыты
- `/admin?key=ADMIN_KEY`: партнёры, лиды, вся переписка без масок

## Запуск
```
cp .env.example .env.local
npm install
npm run dev
```

## Деплой на Vercel
1. Импортировать репозиторий в Vercel.
2. Подключить Upstash Redis через Vercel Marketplace (без него данные в памяти и пропадают).
3. Переменные: см. `.env.example` (TG_TOKEN, TG_ADMIN_CHAT_ID, NEXT_PUBLIC_TG_BOT, ADMIN_KEY, NEXT_PUBLIC_SITE_URL).
4. После деплоя один раз открыть `/api/admin/setup?key=ADMIN_KEY`: подключится Telegram webhook.

## Деплой на свой сервер (VDS, как PLATFORMA)
```
sudo bash deploy/setup.sh [домен]
```
Ставит приложение в `/var/www/sven` (pm2, порт 3100, nginx; без домена доступно на порту 8080), хранит данные в `/var/www/sven-data/kv.json`. Обновление: `bash /var/www/sven/deploy/update.sh`. Ключи Telegram в `/var/www/sven/.env.production`.

## Мои заказы и оценки
Без регистрации: диалоги клиента запоминаются в браузере, в шапке справа появляется «Мои заказы». Там статус, переписка, оценка 1-5 звёзд (можно изменить), комментарий и сумма. Оценить можно только после ответа компании. В списках компании сортируются по оценке.

## Импорт компаний (только из согласованного источника)
```
curl -X POST "https://ВАШ-САЙТ/api/admin/import?key=ADMIN_KEY" -H "Content-Type: application/json" --data @deploy/import.example.json
```
Импортированная компания показывается со ссылкой на площадку-источник, телефоном и кнопкой «Это ваша компания?». Чата у неё нет, заявки ей не рассылаются. Когда владелец регистрируется с тем же телефоном, страница переходит к нему.
